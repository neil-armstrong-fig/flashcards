# webapp

The app: the Flash Cards spaced-repetition PWA (Vite, React 19, Redux Toolkit, Tailwind v4) that works offline. `src/react/` is the screens, `src/redux/` the store, `src/spaced-repetition/` the scheduling logic.

Imports `shared` and `content`. Run it with `pnpm start` from the repository root. See [AGENTS.md](AGENTS.md).
